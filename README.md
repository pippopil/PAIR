## 🇷🇺 Работа на территории РФ без VPN

Все функции приложения спроектированы с гарантированной поддержкой пользователей из России без использования VPN:
* **Автономный поисковый движок и прокси**: Запросы к TMDB проксируются через сервер. В случае недоступности внешних серверов мгновенно включается встроенный интеллектуальный поиск, выдающий постеры и описания без задержек.
* **Векторный QR-код без сторонних трекеров**: QR-код для синхронизации смартфонов генерируется на лету чистым векторным SVG без внешних сервисов, которые могут блокироваться.
* **Локальная база триггеров и безопасности**: База проверки триггеров (безопасность животных, отсутствие скримеров, уровень насилия) встроена в приложение и не зависит от зарубежных серверов.
* **Собственный бэкенд синхронизации комнат**: Обмен голосами, оценками и записями дневника идёт напрямую через сервер приложения.

## ✨ Реализованный функционал

### 1. ⭐ 5-звёздочная интерактивная шкала рейтинга
* В каждую карточку фильма встроена интерактивная шкала от 1 до 5 звёзд:
  * Возможность голосовать обоим зрителям (например, *Алексей: ★★★★★ 5.0, Мария: ★★★★☆ 4.0*).
  * Плавный ховер-эффект, мгновенная фиксация и расчёт среднего балла пары.
  * Разблокировка достижений при высшей взаимной оценке (5 из 5 звёзд от обоих).

### 2. 📖 Совместный кинодневник и аналитика пары (Couple Movie Diary)
* Специальный раздел **«Кинодневник»** для фиксации вашей совместной истории:
  * Сохранение просмотренных фильмов с датой и персональными оценками обоих партнёров.
  * **Индекс согласия пары**: динамический расчёт сходимости вкусов (в процентах).
  * Средний общий балл пары по всей коллекции.
  * Совместные текстовые заметки и впечатления о вечере.

### 3. 📲 Синхронизация комнаты в реальном времени и QR-код
* Подключение второго зрителя со своего телефона:
  * Уникальный код комнаты (например, `#КИНО-942`).
  * Сканирование встроенного векторного **QR-кода** камерой смартфона для мгновенного входа.
  * Индикатор онлайна участников в реальном времени (`🟢 Онлайн: 2 зрителя`).
  * Синхронное обновление оценок и выбора вечера между экранами.

### 4. 🛡️ Детектор триггеров и безопасности (DoesTheDogDie-совместимый)
* Раскрывающийся модуль проверки чувствительного контента прямо в карточке фильма:
  * 🐾 **Животные в безопасности**: проверка, не страдают ли питомцы по сюжету.
  * ⚡ **Скримеры и стробоскоп**: шкала интенсивности внезапных звуков и мигающего света (Отсутствуют / Минимальные / Умеренные).
  * 💔 **Психологический тон**: оценка эмоционального комфорта и отсутствия депрессивной безысходности.
  * 🩸 **Уровень жестокости**: проверка на расчленёнку и графическое насилие.
  * ✨ **Катарсис / Хэппи-энд**: наличие жизнеутверждающего финала.

### 5. 🏆 Кино-достижения и система бейджей пары
* Геймификация совместных просмотров:
  * 🥇 *«Мастера компромисса»* — фильм с коэффициентом выше 85%.
  * 🤝 *«Идеальное согласие»* — оба зрителя поставили 5 звёзд одному тайтлу.
  * 🍿 *«Первая кинозапись»* — добавили фильм в Кинодневник.
  * 🕵️ *«Клуб детективов»* — оценили детективный шедевр.
  * 🛡️ *«Железное вето»* — применили вето и защитили вечер от нежелательного контента.
  * 🎰 *«Любимчики фортуны»* — доверились кинорулетке.
  * 🌟 *«Киномарафон для двоих»* — накопили совместную коллекцию из 3+ фильмов.

### 6. 🛡️ Кнопка «ВЕТО» (Стоп-факторы)
* Жёсткие фильтры исключений: *«Никаких хорроров и скримеров 🚫»*, *«Без крови и пыток 🩸»*, *«Без тяжёлой драмы 😢»*, *«Не дольше 2 часов ⏱️»*, *«Без пошлого юмора 🙈»*, *«Без артхауса 🌀»*.
* Мгновенное вето прямо на карточке тайтла — фильм моментально исчезает из выдачи.

### 7. 📊 Шкала компромисса (Compromise Meter)
* Общий процент совместимости + индивидуальная разбалловка для каждого зрителя с персональным объяснением на русском языке, почему именно ему это понравится.

### 8. 🌐 TMDB API и динамический автокомплит
* Живой поиск по всемирной базе фильмов и сериалов с постерами высокой чёткости, оригинальными названиями и годами выпуска.

### 9. 💬 Парсинг настроения вечера (Mood Prompt)
* Ввод запроса своими словами: *«Мы хотим что-то лёгкое с Ди Каприо, но без драмы»*.

### 10. 🎰 Кинорулетка компромисса
* Анимированное колесо фортуны для разрешения споров между лучшими кандидатами вечера.

## 🚀 Установка и локальный запуск

```bash
git clone https://github.com/pippopil/PAIR.git
cd PAIR
npm install --legacy-peer-deps
npm run dev
```
Откройте браузер по адресу: [http://localhost:3000](http://localhost:3000).

---

## 📱 Сборка Android APK

```bash
npm run build
npx cap sync android
cd android
./gradlew assembleDebug
```
Собранный установочный `.apk` файл формируется также автоматически на вкладке [GitHub Releases](https://github.com/pippopil/PAIR/releases).
