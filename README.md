## 💡 Концепция и ключевая ценность

KinoMatch анализирует вкусы каждого зрителя независимо (любимые жанры, актёров, культовые тайтлы), применяет **абсолютные стоп-факторы («Кнопка Вето»)** и находит не просто скучное «среднее арифметическое», а **идеальный компромисс** с высокой эмоциональной отдачей для каждого участника.

---

## ✨ Реализованный функционал

### 1. 🛡️ Кнопка «ВЕТО» (Стоп-факторы)
* Возможность любого участника категорически исключить нежелательные темы:
  * *«Никаких хорроров и скримеров 🚫»*
  * *«Без крови, расчленёнки и пыток 🩸»*
  * *«Без тяжёлой депрессивной драмы 😢»*
  * *«Не дольше 2 часов (без затянутости) ⏱️»*
  * *«Без пошлого юмора и кринжа 🙈»*
  * *«Никакого заумного артхауса 🌀»*
* Ввод собственного стоп-фактора (например, *«без пауков»*, *«тяжёлый открытый финал»*).
* **Мгновенное вето на фильм:** кнопка блокировки прямо на карточке рекомендации — тайтл навсегда удаляется из выдачи текущего сеанса.

### 2. 📊 Шкала компромисса (Compromise Meter)
* Алгоритм рассчитывает не просто рейтинг, а процент совпадения:
  * **Общий компромисс** (например, **89% Матч**).
  * **Персональная оценка каждого участника**: например, *«Алексей: 92% (любит триллеры и Нолана) • Мария: 86% (оценит комедийный тон и игру актёров)»*.
  * **Обоснование выбора**: развёрнутое пояснение, почему картина станет идеальным мостом между разными вкусами.
  * **Гарантия безопасности**: индикатор *«🛡️ Вето соблюдено (0 табу)»*.

### 3. 🌐 Динамическая интеграция TMDB API
* Поддержка живого поиска по международной базе **The Movie Database (TMDB)**:
  * Живой автокомплит с постерами высокой чёткости, оригинальными названиями, годами выпуска и рейтингами.
  * Возможность найти и добавить в избранное **абсолютно любой фильм или сериал мира**.
  * Блок **«В тренде TMDB»** для мгновенного добавления популярных тайтлов в один клик.
  * Умный fallback-механизм: если API-ключ не задан, поиск динамически работает на встроенном расширенном каталоге и никогда не ломается.

### 4. 💬 Умный ввод вечернего настроения (Smart Mood Prompt)
* Парсинг естественного языка для мгновенного сужения критериев под текущий вечер:
  * *«Мы хотим что-то лёгкое с Ди Каприо, но без драмы»*
  * *«Захватывающий детектив до 100 минут после тяжёлого дня»*
  * Интерактивные чипсы быстрых идей.

### 5. 👫 Режимы: «На двоих» и «Вечеринка» (2–5 человек)
* Мгновенное переключение между парой и компанией друзей.
* В режиме вечеринки алгоритм находит наименьший общий знаменатель для компании до 5 человек, учитывая индивидуальные стоп-факторы каждого гостя.

### 6. 📺 Интеграция со стримингами
* На карточках фильмов отображается реальная доступность на платформах:
  * **Кинопоиск (Плюс)**, **Okko**, **Иви**, **Premier**, **KION**, **START**, **Netflix**, **Apple TV+**.
  * Фильтрация подборок по имеющимся у зрителей подпискам.

### 7. 🔥 Блиц-раунд для двоих (Duo Tinder-батл)
* Интерактивная игра при сомнениях:
  * Участник 1 тайно голосует по топ-5 фильмам (*«Хочу» / «Не хочу»*).
  * Передаёт телефон Участнику 2 для тайного голосования.
  * При взаимном совпадении раздаётся триумфальный **MATCH!** с победной анимацией конфетти 🎉.

### 8. 🎰 Кинорулетка компромисса (Compromise Roulette)
* Анимированное колесо фортуны, случайным образом выбирающее один фильм из числа лучших компромиссных вариантов, если зрители всё ещё не могут договориться.

### 9. 📌 Киносписок и выбор вечера
* Сохранение понравившихся вариантов в личный список (Watchlist).
* Кнопка *«Смотрим этот! 🎉»* с фиксацией выбора вечера и возможностью поделиться в мессенджерах.

## 🔮 Какие ещё функции можно добавить (Roadmap развития)

1. **🍿 Чек-лист киноночи и синхронизированный таймер старта**:
   * Интерактивный список подготовки (*«Попкорн готов», «Напитки охлаждены», «Свет выключен»*).
   * Таймер обратного отсчёта до начала сеанса (*«Старт в 21:00»*) с push-уведомлением на смартфоны.
2. **📖 Совместный дневник просмотров и рейтинг пары (Couple Movie Diary)**:
   * Возможность после просмотра выставить оценки от обоих зрителей (например, *«Алексей: 8/10, Мария: 9/10»*).
   * Накопительная статистика: график сходимости вкусов пары за месяц/год, любимые совместные жанры и актёры.
3. **📲 Синхронизация комнат в реальном времени (WebSockets / WebRTC)**:
   * Подключение к комнате по QR-коду со своих смартфонов без передачи одного устройства из рук в руки.
   * Синхронное свайп-голосование на двух экранах одновременно в реальном времени.
4. **⚠️ Детектор триггеров и спойлеров (DoesTheDogDie API)**:
   * Проверка фильмов на специфические фобии зрителей: *«Погибают ли домашние животные?»*, *«Есть ли сцены клаустрофобии?»*, *«Есть ли резкие звуковые перепады?»*.
5. **🏆 Кино-достижения и бейджи пары**:
   * Геймификация: бейджи *«Мастера компромисса»* (выбрали фильм быстрее 3 минут), *«Ночной киномарафон»* (посмотрели сериал за выходные), *«Открыватели нового»* (посмотрели фильм непривычного для обоих жанра).

## 🚀 Установка и локальный запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/pippopil/PAIR.git
cd PAIR
```

### 2. Установка зависимостей
```bash
npm install --legacy-peer-deps
```

### 3. Настройка переменных окружения
Создайте файл `.env` на основе `.env.example`:
```env
# Опционально: Ключ Gemini API для продвинутого нейросетевого подбора
GEMINI_API_KEY="ВАШ_GEMINI_КЛЮЧ"

# Опционально: Ключ TMDB для живого поиска по всемирной базе фильмов
TMDB_API_KEY="ВАШ_TMDB_API_KEY"
```
*(Приложение полноценно работает и без ключей благодаря интеллектуальному локальному движку компромиссов!)*

### 4. Запуск сервера разработки
```bash
npm run dev
```
Откройте браузер по адресу: [http://localhost:3000](http://localhost:3000).

## 📱 Сборка Android APK

### Локальная сборка:
```bash
npm run build
npx cap sync android
cd android
./gradlew assembleDebug
```
Готовый файл появится по пути: `android/app/build/outputs/apk/debug/app-debug.apk`.

### Автоматическая сборка в облаке (CI/CD):
При каждом коммите или пуше в ветку `main` GitHub Actions автоматически:
1. Собирает проект на **Node.js 22 LTS** и **Java 21 LTS**.
2. Компилирует Android APK через Gradle.
3. Формирует Release с автоматическим номером билда и описанием изменений.
4. Прикрепляет файл `KinoMatch-build-<номер>.apk` на вкладку [GitHub Releases](https://github.com/pippopil/PAIR/releases).
